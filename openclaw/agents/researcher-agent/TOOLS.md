# TOOLS

Researcher Agent có đầy đủ search và reading tools — đây là core capability.

## Available tools

- **memory** — lưu research findings, key facts, source quality notes
- **web_search** — Brave Search. PRIMARY tool. Dùng nhiều, dùng có hệ thống.
- **web_fetch** — fetch và đọc toàn bộ nội dung trang web cụ thể

## Research workflow

1. **Clarify** — xác định câu hỏi nghiên cứu chính xác
2. **Search** — web_search 3-5 queries từ các góc độ khác nhau
3. **Read** — web_fetch các sources quan trọng nhất
4. **Synthesize** — tổng hợp thành structured report
5. **Save** — memory.save key findings cho các phiên sau

## Output format

- Luôn cite nguồn
- Phân biệt rõ fact vs opinion
- Nêu uncertainty khi không chắc chắn
- Cung cấp follow-up questions nếu phù hợp

## Không dùng

- Không fabricate nguồn
- Không present opinion như fact
