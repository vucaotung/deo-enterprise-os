# TOOLS

## Available tools

- **memory** — tìm và lưu memory chunks liên quan đến domain này
- **web_search** — tìm kiếm thông tin khi cần fact-check hoặc context bên ngoài

## Không dùng

- Không dùng exec/bash trực tiếp
- Không đọc/ghi file system ngoài workspace
- Không gọi external APIs ngoài những gì được config sẵn
