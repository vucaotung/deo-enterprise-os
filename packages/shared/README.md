# @deo/shared

Shared domain types, enums, response envelopes, và DTOs cho mọi app/integration.

## Scope (Phase 0 v2 — checklist mục 3.1)

- Base domain types: `auth`, `org`, `projects`, `tasks`, `chat`, `audit`, `automation`, `drive`
- Shared enums: `task_status`, `task_priority`, `project_status`, `channel_type`, `actor_type`
- Response envelope (ADR-05): `{ success, data?, error?: { code, message, details? }, meta? }`
- Create/Update DTOs
